# Launch Lens

[![make.fun competition](https://make.fun/badge/token-radar-01.svg)](https://make.fun/c/token-radar-01)
[![make.fun rank](https://make.fun/badge/token-radar-01/fadlurgkb-alt/launch-lens-token-radar/rank.svg)](https://make.fun/c/token-radar-01)
[![make.fun reward](https://make.fun/badge/token-radar-01/fadlurgkb-alt/launch-lens-token-radar/reward.svg)](https://make.fun/c/token-radar-01)

Launch Lens is a deterministic, snapshot-only token launch radar built for the
[make.fun `token-radar-01` competition](https://make.fun/c/token-radar-01). It ranks protocol records by a transparent implied-value scenario, distinguishes protocols with recorded token metadata from those without it, and pairs every row with a practical, risk-aware farming plan.

The dashboard is designed to answer three questions quickly:

1. Which protocol records stand out on value, growth, maturity, and chain breadth?
2. Does the supplied DefiLlama snapshot record a token for the protocol?
3. What small, verifiable steps could a reader take without assuming an airdrop exists?

## Value model

For each protocol, `buildRows` in `lib/model.ts` computes:

```text
implied value = TVL
              × category multiple
              × seven-day growth factor
              × tracked-age factor
              × chain-breadth factor
              × token-record factor
```

The result is rounded to the nearest $1,000 and used to produce a stable rank, with the protocol slug as the deterministic tie-breaker.

| Component | Treatment |
| --- | --- |
| TVL | Snapshot TVL in whole US dollars; the base of the scenario. |
| Category | Explicit multiples for selected categories, with `0.14` as the fallback. |
| Seven-day growth | `1 + change_7d / 100 × 0.55`, clamped to `0.72–1.34`; missing growth is neutral at `1.00`. |
| Tracked age | Log-scaled from `listed_at`, clamped to `0.86–1.22`; missing age uses `0.88`. |
| Chain breadth | Adds `0.025` per additional chain, capped at `1.14`. |
| Token record | `1.00` when both symbol and Gecko ID are absent; `0.01` for recorded-token benchmark rows. |

Launch candidates exclude categories and names that strongly indicate CEX, bridge, liquid staking/restaking, wrapped or staked products, exchange-branded products, or versioned derivatives. The model selects up to 200 launch candidates and 32 recorded-token benchmarks, then guarantees that every slug in the supplied watchlist is present. Runtime invariants reject fewer than 100 rows, incomplete watchlist coverage, or invalid rank/value ordering.

The multipliers are an interpretable comparison heuristic—not a forecast, token price target, or claim about fully diluted valuation.

## Offline dashboard

The generated dashboard works without external services or remote assets. It includes:

- search across protocol name, category, and chains;
- filters for token-record status, risk, and category;
- sortable rank, name, implied value, TVL, growth, age, and risk columns;
- a detail view with thesis, model factors, confidence, and chain-aware execution steps;
- explicit labels separating no-token-record candidates from recorded-token benchmarks;
- costs, suggested duration, position limits, withdrawal checks, explorer verification, and approval-revocation guidance.

`main.ts` embeds generated snapshot results in `dashboard/data.dat`, copies the dashboard and screenshots into the output, writes `board.json`, and creates the canonical `dossier.json` with `buildDossier` from `vendor/makefun-board.ts`.

## Deterministic build

Requirements:

- Node.js 22.18 or newer;
- the official sealed snapshot from the competition kit;
- no installed packages and no network access.

From the repository root, with the official kit in the adjacent directory:

```bash
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts \
  --input ../token-radar-01-kit/input/snapshot.json
```

The generator replaces the directory named by `MAKEFUN_OUTPUT_DIR`, so use a dedicated output path. A successful run writes:

```text
out/
|-- board.json
|-- dossier.json
|-- dashboard/
|   |-- app.css
|   |-- app.js
|   |-- data.dat
|   `-- index.html
`-- screenshots/
    |-- 1-board.png
    |-- 2-detail.png
    `-- 3-filtered.png
```

To verify reproducibility locally:

```bash
rm -rf out-a out-b
MAKEFUN_OUTPUT_DIR=out-a node main.ts \
  --input ../token-radar-01-kit/input/snapshot.json
MAKEFUN_OUTPUT_DIR=out-b node main.ts \
  --input ../token-radar-01-kit/input/snapshot.json
diff -qr out-a out-b
```

No output from `diff` means every generated byte matches.

## Farming plans and safety

Each plan favors genuine, limited protocol use rather than manufactured activity. It starts with free research, proposes a small trial transaction, caps suggested exposure, separates actions over time, and ends with independent verification and a tested withdrawal.

Always treat protocol interaction as potentially loss-making:

- verify the official application and contract addresses independently;
- read current eligibility rules, audits, governance notices, and geographic restrictions;
- test with a small amount before increasing exposure;
- avoid leverage, wash trading, sybil behavior, and activity performed only to imitate volume;
- monitor liquidation health, liquidity, contract upgrades, and bridge finality where relevant;
- save transaction hashes, test a partial withdrawal, and revoke unused approvals;
- never risk funds you cannot afford to lose.

## Limitations

- The input is a sealed historical snapshot, not live market data.
- “No token recorded” means both `gecko_id` and `symbol` are absent from that snapshot. It does **not** prove that no token exists.
- A protocol may launch no token, may use eligibility rules not represented here, or may prohibit the activity a reader considers.
- TVL and seven-day change can be volatile, incomplete, or affected by accounting differences.
- Category multipliers and risk labels are model assumptions, not audited risk ratings.
- Implied value is a comparative scenario generated by this project, not a valuation supplied or endorsed by DefiLlama or make.fun.
- Farming steps are educational workflow guidance, not financial, legal, tax, or investment advice and never a promise of rewards.
